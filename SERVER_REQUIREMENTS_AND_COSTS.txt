3. STEP-BY-STEP SERVER DEPLOYMENT GUIDE (FOR LINUX VPS)
================================================================================

STEP 1: POINT DOMAIN TO SERVER
   - Go to GoDaddy -> DNS Management -> Add/Edit 'A' Record:
     Type:  A
     Host:  @
     Value: <Your Server Public IP Address>
     TTL:   Default / 600 seconds

STEP 2: INSTALL CORE SOFTWARE ON VPS (Run via SSH Terminal)
   sudo apt update && sudo apt upgrade -y
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs nginx git certbot python3-certbot-nginx
   sudo npm install -g pm2

STEP 3: DEPLOY BACKEND API
   cd /var/www
   # Upload or clone your project files here
   cd /var/www/pg-site/server
   npm install --production
   pm2 start server.js --name "pg-backend"
   pm2 save
   pm2 startup

STEP 4: BUILD & DEPLOY FRONTEND
   cd /var/www/pg-site/client
   npm install
   npm run build
   # Build output will be created in /var/www/pg-site/client/dist

STEP 5: CONFIGURE NGINX WEB SERVER
   Create config file: sudo nano /etc/nginx/sites-available/pg-site
   Insert following configuration:

   server {
       listen 80;
       server_name yourdomain.com www.yourdomain.com;

       # Frontend React Single Page Application (Clean URLs)
       location / {
           root /var/www/pg-site/client/dist;
           index index.html;
           try_files $uri $uri/ /index.html;
       }

       # Backend Express API Proxy
       location /api/ {
           proxy_pass http://127.0.0.1:5050;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
       }
   }

   Enable site & reload Nginx:
   sudo ln -s /etc/nginx/sites-available/pg-site /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl restart nginx

STEP 6: SECURE SITE WITH FREE SSL (HTTPS)
   sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
   (Certbot will automatically configure HTTPS and renew certificates)
